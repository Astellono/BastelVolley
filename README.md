# Защита в волейболе

Интерактивная схема для тренера. Чтобы запустить, откройте `index.html` двойным щелчком: приложение работает в браузере, устанавливать ничего не нужно.

- **Зоны и схемы:** атака соперника, переброс, наша атака (страховка), свободная расстановка.
- **Планшет:** игроки, стрелки, перо, блок с тенью и анимация комбинаций.

Нарисованные зоны и схемы сохраняются в этом браузере на этом компьютере. Шрифты загружаются из интернета; без него страница работает со стандартным шрифтом.
